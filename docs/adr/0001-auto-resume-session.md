# ADR-0001: Pre-send summarization with prompt-guided compression for Auto Resume

We are adding an "Auto Resume Session" feature that compresses conversation history before sending the user's next prompt, triggered when session token usage exceeds a configurable threshold. We chose a **pre-send architecture** (coordinator layer checks threshold, calls `Summarize(prompt)`, then dispatches the original prompt) over the existing mid-turn `StopWhen` callback because the summarizer needs the user's pending input for prompt-guided compression. The summarizer defaults to the large model but can be switched to the small model (with greedy oldest-to-newest chunking when the small model's context window is too small). When auto-resume is active, the old `StopWhen` auto-summarize is gated off rather than removed.
